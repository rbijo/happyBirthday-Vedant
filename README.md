# Happy Birthday, Vedant!

Responsive birthday page with poppable balloons, candle smoke, multi-step cake cutting, slice selection and confetti. No build tools or backend required.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the published URL to appear in the Pages section.

Google Fonts is optional; system font fallbacks are provided. All interactions run in the browser.
